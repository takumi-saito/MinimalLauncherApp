# Architecture Decision Record

`docs/adr/` に意思決定の記録を蓄積する。運用ルールの正典は
[docs/adr/README.md](../../../docs/adr/README.md)。このスキルはその手順を実行する。

## 新しい ADR を書く

### 1. そもそも書くべきか判断する

**基準は「あとで覆すのにどれくらいかかるか」。** 数分で戻せるなら書かない。
数日かかるなら書く。

| 書く | 書かない |
|------|---------|
| ライブラリ・フレームワークの選定 | パッチバージョンの更新 |
| テスト戦略 | バグ修正 |
| ディレクトリ構成・レイヤ分割 | 実装の詳細 |
| データモデル・状態管理の方針 | 設定値の変更 |
| CI/CD やリリースフローの方針 | 方針が変わらないリファクタリング |

書かないほうがよいと判断したら、その理由を述べて終了する。ADR の本数を増やすこと自体に
価値は無い。

### 2. 採番する

`docs/adr/` の既存ファイルを見て、最大値 + 1 をゼロ埋め 4 桁にする。
ファイル名は `NNNN-title-with-dashes.md`（slug は ASCII、タイトル本文は日本語で可）。

### 3. 書く

`docs/adr/template.md` をコピーして埋める。守ること:

- **Context には「当時なにを知っていたか」を再現できる事実を書く。** バージョン番号、
  制約、計測値など、あとから検証できるもの。「〜が課題だった」だけでは足りない。
- **Decision には採用しなかった選択肢と、採らなかった理由を必ず書く。**
  「なぜ A にしたか」より「なぜ B ではないか」のほうが後から効く。一度見送った案が
  再提案されるのを防ぐのが ADR の主目的のひとつ。
- **Bad を必ず埋める。** トレードオフの無い決定は存在しない。Good しか書けていない
  ADR は、検討が足りていないか都合の悪い点を隠している。埋まらないなら、まだ ADR を
  書く段階ではない。
- **1〜2 ページに収める。** 詳細な手順は別ドキュメント（例: `docs/vrt.md`）に切り出し、
  ADR からリンクする。
- Status は、実装済みなら `Accepted`、実装前に方針だけ決めたなら `Proposed`。

**推測で書かない。** 事実が確認できない部分は、ユーザーに聞くか、その旨を明記する。
「当時こう考えたはず」と埋めると、事実と願望の区別がつかない記録になる。

### 4. 索引を更新する

`docs/adr/README.md` の索引テーブルに 1 行足す。**この手順を飛ばさない** — 索引に
無い ADR は発見されない。

### 5. コミットする

実装と同じ PR に含める。PR がマージされた時点で `Accepted` とみなす。

## 既存の ADR を調べる

「なぜこうなっているのか」を問われたとき、実装を読む前に `docs/adr/README.md` の索引を
見る。該当する ADR があれば、そこに書かれた理由と却下した選択肢を根拠として答える。

ADR に書かれた決定に反する提案をしそうになったら、まずその ADR を読むこと。
反する提案自体は禁止ではないが、「ADR-000N ではこう決まっているが、〜の理由で
見直す価値がある」と、既存の決定を踏まえた形で提示する。

## 決定を置き換える

**Accepted な ADR は書き換えない。** 決定が変わったら:

1. 新しい ADR を書く。Context に「ADR-000N（日付）ではこう決めたが、その後こう変わった」
   を含める
2. 新しい ADR に `**Supersedes**: [ADR-000N](000N-xxx.md)` を書く
3. 古い ADR の Status を `Superseded` にし、`**Superseded by**: [ADR-000M](000M-xxx.md)`
   を足す
4. 索引の Status を両方更新する

古い ADR は消さない。「当時どう考えていたか」が消えると ADR の価値が無くなる。
`Rejected`（検討して見送った）も同様に残す。

## 注意

- 遡及的な ADR を勝手に量産しない。ADR 導入以前の決定（Hilt の採用、Compose と View
  システムの併用など）は、該当箇所を触る機会に、そのとき分かっている事実の範囲で書く。
- 索引の日付は ADR 本文の `Date` と一致させる。
